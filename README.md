## 🛠️ Tecnologias Utilizadas
- HTML5: Estruturação semântica dos botões e visor.
- CSS3: - Layout dinâmico com CSS Grid.
- Estilização avançada com `border-radius` e transições.
- Tipografia de sistema.

- JavaScript: - Lógica de cálculo.
- Manipulação do DOM para atualização do visor em tempo real.
